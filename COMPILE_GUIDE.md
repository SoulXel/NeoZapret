# 📦 Руководство по компиляции NeoZapret в Visual Studio Insiders

## 🎯 Способ 1: Компиляция через Visual Studio Insiders (GUI) - РЕКОМЕНДУЕТСЯ

### Шаг 1: Откройте проект
1. Запустите **Visual Studio Insiders**
2. Нажмите **Файл → Открыть → Проект или решение...** (или `Ctrl+Shift+O`)
3. Выберите файл `NeoZapret.sln` в корневой папке проекта
4. Нажмите **Открыть**

### Шаг 2: Установите необходимые компоненты (если требуется)
Убедитесь, что установлена рабочая нагрузка:
- **Разработка классических приложений .NET** (.NET Framework)

Если не установлена:
1. **Сервис → Получить инструменты и компоненты...**
2. Выберите **Разработка классических приложений .NET**
3. Нажмите **Изменить** и дождитесь установки

### Шаг 3: Скомпилируйте проект
1. Выберите конфигурацию: **Release** (вверху панели инструментов, рядом с зеленой кнопкой запуска)
2. Выберите платформу: **Любой ЦП** (Any CPU)
3. Нажмите **Сборка → Собрать решение** (или `Ctrl+Shift+B`)

### Шаг 4: Запустите приложение
- Нажмите **Отладка → Запуск без отладки** (или `Ctrl+F5`)
- Или найдите скомпилированный файл: `NeoZapret\bin\Release\net472\NeoZapret.exe`

---

## ⚡ Способ 2: Компиляция через скрипт build.bat

### Шаг 1: Откройте Командную строку разработчика
1. В меню Пуск найдите **Командная строка разработчика для VS** или
2. Запустите PowerShell в папке проекта

### Шаг 2: Запустите скрипт сборки
```batch
cd C:\Users\xeldi\Desktop\NeoZapret
build.bat
```

Скрипт автоматически:
- Проверит наличие MSBuild
- Соберет проект в Release режиме
- Покажет путь к скомпилированному файлу

---

## 🔧 Способ 3: Компиляция через командную строку

### Шаг 1: Откройте Командную строку разработчика
В Visual Studio Insiders:
1. **Сервис → Командная строка → Командная строка разработчика**

### Шаг 2: Перейдите в папку проекта
```batch
cd C:\Users\xeldi\Desktop\NeoZapret
```

### Шаг 3: Скомпилируйте проект
```batch
msbuild NeoZapret.sln /p:Configuration=Release /p:Platform="Any CPU" /t:Rebuild
```

## ❌ Решение проблем

### Проблема: "Target framework not found"
**Решение:** Установите .NET Framework 4.7.2 Developer Pack
- Скачайте: https://dotnet.microsoft.com/download/dotnet-framework/net472

### Проблема: "MSBuild not found"
**Решение:** 
1. Убедитесь, что Visual Studio Insiders полностью установлен
2. Запустите Developer Command Prompt через Visual Studio
3. Или добавьте путь к MSBuild в PATH:
   ```
   C:\Program Files\Microsoft Visual Studio\2022\Preview\MSBuild\Current\Bin
   ```

### Проблема: "UseWindowsForms not found"
**Решение:** Установите рабочую нагрузку ".NET desktop development" в Visual Studio

### Проблема: Ошибки компиляции
**Решение:** 
1. Выберите **Сборка → Очистить решение**
2. Затем **Сборка → Пересобрать решение**
3. Проверьте, что все файлы проекта сохранены

## 📝 Дополнительная информация

### Конфигурации сборки:
- **Debug** - для отладки (медленнее, с символами)
- **Release** - для распространения (быстрее, оптимизированная)

### Для распространения:
После компиляции скопируйте в папку с `NeoZapret.exe`:
- Папку `bin\` (с winws.exe и другими файлами)
- Папку `lists\` (со списками доменов)
