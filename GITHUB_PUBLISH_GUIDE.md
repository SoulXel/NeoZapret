## Шаг 1: Создание репозитория на GitHub

1. **Войдите в GitHub**:
   - Откройте https://github.com
   - Войдите в свой аккаунт (если нет аккаунта - создайте)

2. **Создайте новый репозиторий**:
   - Нажмите кнопку **"+"** в правом верхнем углу
   - Выберите **"New repository"**

3. **Настройте репозиторий**:
   - **Repository name**: `NeoZapret` (или другое название)
   - **Description**: `DPI Bypass Tool - Обход блокировок РФ 2025`
   - **Visibility**: 
     - ✅ **Public** (для открытого проекта)
     - или **Private** (если хотите закрытый репозиторий)
   - ❌ **НЕ** отмечайте "Initialize with README" (у нас уже есть README)
   - ❌ **НЕ** добавляйте .gitignore или license (у нас уже есть)
   - Нажмите **"Create repository"**

## Шаг 2: Подготовка локального репозитория

### Вариант А: Если Git еще не инициализирован

Откройте **PowerShell** или **Git Bash** в папке проекта и выполните:

```bash
# Перейдите в папку проекта
cd C:\Users\xeldi\Desktop\NeoZapret

# Инициализируйте Git репозиторий
git init

# Добавьте все файлы (кроме игнорируемых)
git add .

# Создайте первый коммит
git commit -m "Initial commit: NeoZapret v3.1.0"

# Добавьте удаленный репозиторий (замените USERNAME на ваш GitHub username)
git remote add origin https://github.com/USERNAME/NeoZapret.git

# Переименуйте основную ветку в main (современный стандарт)
git branch -M main

# Загрузите код на GitHub
git push -u origin main
```

### Вариант Б: Если Git уже инициализирован

```bash
# Проверьте статус
git status

# Добавьте все изменения
git add .

# Создайте коммит
git commit -m "Prepare for GitHub release v3.1.0"

# Добавьте удаленный репозиторий (если еще не добавлен)
git remote add origin https://github.com/USERNAME/NeoZapret.git

# Загрузите код

```

## Шаг 3: Создание Release на GitHub

1. **Перейдите на страницу репозитория**:
   - Откройте ваш репозиторий на GitHub

2. **Создайте Release**:
   - Нажмите на **"Releases"** в правой части страницы
   - Или перейдите по ссылке: `https://github.com/USERNAME/NeoZapret/releases`
   - Нажмите **"Create a new release"**

3. **Заполните информацию о релизе**:
   - **Tag version**: `v3.1.0` (или `v3.1.0-alpha`)
   - **Release title**: `NeoZapret v3.1.0 - Stable Release`
   - **Description**: Скопируйте содержимое из `CHANGELOG.md` или напишите описание

4. **Прикрепите файлы (опционально)**:
   - Если у вас есть скомпилированный `.exe`, перетащите его в поле "Attach binaries"
   - Или создайте ZIP архив с готовой версией приложения

5. **Опубликуйте**:
   - Выберите **"Publish release"**
