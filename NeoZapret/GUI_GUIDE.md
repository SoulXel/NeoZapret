# NeoZapret GUI - Руководство пользователя

## 🎨 Интерфейс приложения

### Главное окно

Приложение состоит из **двух панелей**:

**Левая панель (300px):**
- Логотип NEOZAPRET
- Настройки автостарта
- Настройки отображения

**Правая панель (600px):**

## 🚀 Основные функции

### 1. Запустить обход
Запускает одну из 4 стратегий обхода.

### 2. Остановить обход  
Мгновенно останавливает работу обхода.

### 3. Управление службой
Установка/удаление Windows службы для автозапуска.

### 4. Диагностика
Проверка состояния системы и служб.

### 5. Очистка
Удаление старых логов и временных файлов.

### 6. Доп. настройки
Продвинутые параметры обхода.

### 7. Генератор стратегий (NEW)
Создайте свою собственную стратегию обхода с настраиваемыми параметрами.

### 8. Тест стратегий (NEW)
Автоматически определите оптимальную стратегию для вашего подключения.

## 🎨 Генератор стратегий

Создайте собственную стратегию с полным контролем параметров:

**Параметры:**
- **UDP повторы**: Количество повторов DPI desync для UDP (1-20)
- **TCP повторы**: Количество повторов для TCP (1-20)
- **Режим DPI desync**: Выбор метода десинхронизации
  - `fake` - Быстрый обход
  - `multisplit` - Стабильный обход
  - `fakedsplit` - Смешанный метод
  - Комбинации методов
- **Cutoff режим**: 
  - `n1` - Быстро (минимум задержки)
  - `n2` - Средне
  - `n3` - Медленно (максимальная надежность)
- **TLS fooling**: Обход TLS детектов
- **QUIC fake packets**: Подделка QUIC пакетов

**Использование:**
1. Откройте "Генератор стратегий"
2. Настройте параметры
3. Нажмите "Сгенерировать"
4. Сохраните в файл при необходимости

## ⚙️ Настройки

### Запуск с Windows
Включает автостарт NeoZapret при загрузке ОС.

### Сворачивать в трей
Скрывает окно в системный трей при минимизации.

### Игровой фильтр
Добавляет фильтрацию портов для игр (Battlefield, Steam и др.).

### Дополнительные настройки

**DNS сервер:**
- Можно указать кастомный DNS (например, 1.1.1.1, 8.8.8.8)

**TCP/UDP повторы:**
- Увеличивает/уменьшает количество повторов десинхронизации
- Больше = надежнее, но медленнее

**Cutoff режим:**
- n1 - быстро (минимум задержки)
- n2 - средне
- n3 - медленно (максимальная надежность)

**Прокси сервер:**
- Опциональная поддержка SOCKS5 прокси

## 🛠️ Диагностика

Проверяет:
- ✓ Base Filtering Engine (BFE)
- ✓ TCP timestamps
- ✓ Конфликты WinDivert
- ✓ Активность процесса обхода

Выводит цветную статистику:
- 🟢 Зеленый - все ОК
- 🟡 Желтый - предупреждения
- 🔴 Красный - ошибки

## 💡 Советы

**Для лучшей скорости:**
- Используйте Быструю стратегию
- Отключите игровой фильтр (если не играете)
- Установите Cutoff=n1

**Для максимальной надежности:**
- Используйте Максимальную защиту
- Включите игровой фильтр
- Установите максимальные повторы

**Для стабильной работы:**
- Установите как Windows службу
- Включите автозапуск
- Не забудьте проверить диагностику
