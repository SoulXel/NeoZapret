# NeoZapret GUI - Windows приложение

Графическое приложение для управления обходом блокировок на основе zapret.

## 📖 Документация

- **GUI_GUIDE.md** - Полное руководство пользователя
- **ICON_README.md** - Как добавить иконку приложения

## 🛠️ Сборка приложения

### Требования
- Visual Studio 2019 или выше
- .NET Framework 4.7.2 или выше
- Windows SDK

### Инструкция по сборке

1. Откройте `NeoZapret.sln` в Visual Studio
2. Выберите конфигурацию **Release** (Release | Any CPU)
3. Нажмите **Build** → **Build Solution** (или F6)
4. Скомпилированный файл `NeoZapret.exe` будет в папке `bin\Release\net472\`

## 📦 Распространение приложения

После сборки скопируйте следующие файлы в одну директорию:

```
NeoZapret/
├── NeoZapret.exe          # Собранное приложение
├── bin/                   # Копируем из исходного проекта
│   ├── winws.exe
│   ├── WinDivert.dll
│   ├── WinDivert64.sys
│   ├── cygwin1.dll
│   └── *.bin
├── lists/                 # Копируем из исходного проекта
│   ├── list-general.txt
│   ├── list-google.txt
│   ├── list-exclude.txt
│   ├── ipset-all.txt
│   └── ipset-exclude.txt
└── logs/                  # Создается автоматически
```

## 🚀 Использование

1. Запустите `NeoZapret.exe` **от имени администратора**
2. Приложение автоматически проверит права и предложит их запросить при необходимости
3. Используйте кнопки на главной форме для управления

## ✨ Функционал

### Главное меню (v2.2.0)
- **🚀 Запустить обход** - Запуск обхода с выбором стратегии
- **⏹ Остановить обход** - Мгновенная остановка процесса
- **⚙️ Управление службой** - Установка/удаление Windows службы
- **🔍 Диагностика** - Проверка BFE, TCP timestamps, конфликтов
- **🧹 Очистка** - Удаление старых логов и временных файлов
- **⚙️ Доп. настройки** - Расширенные параметры

**Настройки:**
- ✅ Запуск с Windows (автозагрузка)
- ✅ Сворачивать в трей (работа в фоне)
- ✅ Игровой фильтр (для игр)

### Стратегии обхода
1. **🎯 Рекомендуемая** - Для Cursor, Discord, YouTube, игры
2. **⚡ Быстрая** - Баланс скорости и надежности

## ⚙️ Управление службой

Приложение позволяет установить обход как Windows службу для автоматического запуска при загрузке системы:

1. Нажмите **⚙️ Управление службой**
2. Выберите **📦 Установить как службу Windows**
3. Выберите стратегию
4. Служба будет установлена и запущена автоматически

## 🔧 Диагностика

Приложение проверяет:
- Base Filtering Engine (BFE)
- TCP Timestamps
- Конфликты с WinDivert
- Активность процесса обхода
- Состояние службы

## 📝 Лог операций

Все операции логируются в текстовое поле с цветовой маркировкой:
- 🟢 Зеленый - Успешные операции
- 🔴 Красный - Ошибки
- 🟡 Желтый - Предупреждения
- 🔵 Синий - Информация

## ⚠️ Важно

- Приложение **требует** прав администратора
- Base Filtering Engine должен быть включен
- При установке службы может потребоваться подтверждение UAC
