# 🔧 Решение проблемы блокировки файла при сборке

## Проблема
```
Не удалось скопировать "obj\Release\net472\NeoZapret.exe" в "bin\Release\net472\NeoZapret.exe"
Процесс не может получить доступ к файлу, так как этот файл используется другим процессом
```

## Причина
Приложение NeoZapret уже запущено и блокирует свой исполняемый файл (.exe), поэтому компилятор не может его перезаписать.

## ✅ Решения

### Вариант 1: Закрыть приложение вручную
1. Закройте все окна NeoZapret
2. Проверьте системный трей (иконка возле часов) - щелкните правой кнопкой и выйдите
3. Запустите сборку снова

### Вариант 2: Использовать скрипт автоматической очистки
1. Запустите `PRE_BUILD_CLEAN.bat` перед сборкой
2. Скрипт автоматически закроет все процессы NeoZapret и winws
3. После этого запустите сборку в Visual Studio

### Вариант 3: Принудительное закрытие через Диспетчер задач
1. Откройте Диспетчер задач (Ctrl+Shift+Esc)
2. Найдите процессы:
   - `NeoZapret.exe`
   - `winws.exe`
3. Завершите их принудительно
4. Запустите сборку

### Вариант 4: Настройка Visual Studio (рекомендуется)
Добавьте автоматическую очистку перед сборкой:
1. В Visual Studio откройте `Project Properties` → `Build Events`
2. Добавьте в `Pre-build event command line`:
   ```batch
   taskkill /F /IM NeoZapret.exe 2>nul & taskkill /F /IM winws.exe 2>nul
   ```

## 📝 Дополнительные советы

- Всегда закрывайте приложение перед сборкой
- Если используете автозапуск с Windows - отключите его на время разработки
- Используйте скрипты `PRE_BUILD_CLEAN.bat` или `KILL_BEFORE_BUILD.bat` для удобства

## ⚠️ Важно
При сборке в режиме Release убедитесь, что:
- Приложение полностью закрыто
- Все процессы winws остановлены
- Файл .exe не используется другими программами (антивирус, файловый менеджер и т.д.)
