# Инструкция по сборке и использованию NeoZapret

## 🎯 Быстрый старт

**NeoZapret - современное GUI приложение!**

Просто установите или соберите NeoZapret.exe!

---

## 📦 Варианты использования

### ⭐ Вариант 1: Готовый установщик (РЕКОМЕНДУЕТСЯ)

**Преимущества:**
- ✅ Не требует сборки
- ✅ Автоматическая установка
- ✅ Все зависимости включены
- ✅ Создание ярлыков в меню Пуск

**Запуск:**
1. Скачайте `NeoZapret-Setup.exe`
2. Запустите от имени администратора
3. Следуйте инструкциям установщика
4. Готово!

---

### 🛠️ Вариант 2: Сборка из исходников

**Требования:**
- Visual Studio 2019/2022 (Community Edition бесплатна)
- Или Visual Studio Build Tools

**Инструкция:**

1. **Установите Visual Studio:**
   - Скачайте: https://visualstudio.microsoft.com/downloads/
   - Выберите "Visual Studio Community" (бесплатная)
   - При установке выберите рабочую нагрузку ".NET desktop development"

2. **Соберите проект:**
   ```batch
   build.bat
   ```

3. **Запустите приложение:**
   - Откройте `NeoZapret\bin\Release\net472\NeoZapret.exe`
   - Или запустите сборку из Visual Studio (F5)

4. **Создайте установщик (опционально):**
   ```batch
   build_setup.bat
   ```

---

### 📦 Вариант 3: Портативная версия

**Без установки:**

```batch
# 1. Соберите приложение
build.bat

# 2. Создайте релиз
release.bat

# 3. Запустите NeoZapret.exe из папки NeoZapret-Release\
```

## 🎮 Использование NeoZapret

**Запуск:**
1. Запустите `NeoZapret.exe` **от имени администратора**
2. Используйте GUI интерфейс для управления
3. Выберите стратегию и запустите обход

**Основные функции:**
- 🚀 Запустить/Остановить обход
- ⚙️ Управление службой Windows
- 🔍 Диагностика системы
- 🧹 Очистка логов
- ⚙️ Дополнительные настройки

**Настройки:**
- ☑ Автозапуск с Windows
- ☑ Сворачивание в трей
- ☑ Игровой фильтр

## 📦 Создание дистрибутива

### Способ 1: Скрипт сборки

```batch
build_setup.bat
```

Создаст `NeoZapret-Setup.exe` установщик.

### Способ 2: Ручная сборка

1. Соберите приложение (`build.bat`)
2. Скопируйте `bin/` и `lists/` в папку с `NeoZapret.exe`
3. Создайте архив или установщик

---

## 🆘 Решение проблем

**Проблема:** "MSBuild не найден"
**Решение:** Установите Visual Studio Community или Build Tools

**Проблема:** "Недостаточно прав администратора"
**Решение:** Запустите от имени администратора

**Проблема:** "Не удалось запустить службу"
**Решение:** Проверьте диагностику и убедитесь, что BFE включен
