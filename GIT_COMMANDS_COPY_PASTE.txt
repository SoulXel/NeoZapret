===========================================
КОМАНДЫ ДЛЯ КОПИРОВАНИЯ И ВСТАВКИ
===========================================

1. Настройка Git (замените email):
git config user.name "SoulXel"
git config user.email "ваш@email.com"

2. Добавление файлов:
git add .

3. Создание коммита:
git commit -m "Initial commit: NeoZapret v3.1.0 - Production ready"

4. Подключение к GitHub (ЗАМЕНИТЕ YOUR_USERNAME!):
git remote add origin https://github.com/YOUR_USERNAME/NeoZapret.git

5. Переименование ветки:
git branch -M main

6. Загрузка на GitHub:
git push -u origin main
