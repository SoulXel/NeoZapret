## 📋 Описание

**NeoZapret** — комплексное GUI решение для обхода блокировок с несколькими стратегиями. Основано на [winws](https://github.com/Flowseal/winws) и использует продвинутые методы обхода сетевых ограничений.

**Version 3.1.0** - Генератор стратегий и автоопределение оптимального обхода!

3. Готово!

## 🎮 Использование

### Главное окно NeoZapret

Запустите **NeoZapret.exe** для доступа к GUI интерфейсу:

**Основные функции:**
- 🚀 Запустить обход
- ⏹ Остановить обход
- ⚙️ Управление службой
- 🔍 Диагностика
- 🧹 Очистка
- ⚙️ Дополнительные настройки
- 🎨 Генератор стратегий
- 🧪 Тест стратегий

**Настройки:**
- ☑ Запуск с Windows (автозагрузка)
- ☑ Сворачивать в трей
- ☑ Игровой фильтр

### Выбор стратегии обхода

Проект содержит 4 оптимизированные стратегии:

| Стратегия | Описание | Скорость | Рекомендация |
|-----------|----------|----------|--------------|
| 🎯 Рекомендуемая | Для Cursor, Discord, YouTube | ⭐⭐⭐⭐⭐ | ✅ Лучшая для повседневного использования |
| ⚡ Быстрая | Баланс скорости и надежности | ⭐⭐⭐⭐⭐ | Для минимального пинга |
| 🔒 Максимальная защита | Если ничего не помогает | ⭐⭐⭐⭐ | Когда заблокировано все |
| 🎮 Только игры | Battlefield, Steam и т.д. | ⭐⭐⭐⭐ | Для игровых серверов |

**Советы по выбору**:
- 💻 **Для Cursor, GitHub, AI сервисов**: Используйте 🎯 Рекомендуемую
- 🎮 **Для игр (Battlefield 6 и т.д.)**: Используйте 🎮 Игры
- 🌐 **Для максимальной скорости**: Используйте ⚡ Быструю
- 🔒 **Если ничего не помогает**: Используйте 🔒 Максимальную защиту

### Управление службой

**Установка как службы Windows**:
1. Запустите **NeoZapret.exe**
2. Нажмите кнопку **⚙️ Управление службой**
3. Выберите **📦 Установить как службу Windows**
4. Выберите стратегию
5. Служба будет установлена и запущена автоматически

**Другие действия**:
- 🗑️ Удалить службу
- 🔄 Перезапустить службу

## 🔍 Диагностика

Инструмент включает встроенную диагностику, которая проверяет:

- ✅ Работу Base Filtering Engine
- ✅ TCP timestamps
- ✅ Конфликты с WinDivert
- ✅ Запущенные процессы обхода
- ✅ Конфликтующие службы

**Для запуска диагностики**: **NeoZapret.exe** → **🔍 Диагностика**

## 🔧 Решение проблем

### Проблема: Discord все еще заблокирован

**Решения**:
1. Запустите диагностику (**NeoZapret.exe** → **🔍 Диагностика**)
2. Попробуйте другую стратегию (например, 🔒 Максимальная защита)
3. Перезагрузите компьютер
4. Проверьте, что служба запущена

### Проблема: Низкая скорость / Высокий пинг

**Решения**:
1. Используйте ⚡ Быструю стратегию
2. Отключите игровой фильтр (если не играете онлайн)
3. Закройте другие программы, использующие интернет
4. Проверьте диагностику на конфликты

### Проблема: "Connection failed" в Cursor

**Решения**:
1. Используйте 🎯 Рекомендуемую стратегию
2. Убедитесь, что обход запущен
3. Проверьте диагностику
4. Перезапустите обход

### ⚡ Оптимизация для минимального пинга

**Для игр**:
1. Используйте 🎮 Игры стратегию
2. Включите игровой фильтр
3. Проверьте, что нет конфликтов

**Для обычного интернета**:
1. Используйте ⚡ Быструю стратегию
2. Отключите игровой фильтр
3. Проверьте диагностику
