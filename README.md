# 🔓 NeoZapret - Обход блокировок РФ 2025

Современное GUI приложение для обхода DPI (Deep Packet Inspection) блокировок в России. Основано на [winws](https://github.com/Flowseal/winws).

**Version 3.1.0**

## 🚀 Быстрый старт

1. Скачайте **NeoZapret** из Releases
2. Запустите от имени администратора
3. Готово!

## ✨ Основные возможности

### 🔓 Обход блокировок
- Discord (включая Discord.media), YouTube, Google
- GitHub, GitLab, Bitbucket, Cursor Editor
- AI сервисы: OpenAI, Claude, Perplexity
- Игры: Steam, Epic Games, Battlefield, EA Games
- Социальные сети: Reddit, Twitter/X, Instagram, Facebook, TikTok
- Стриминг: Twitch, Netflix, Spotify, SoundCloud

### ⚙️ Стратегии обхода

**Общие стратегии:**
- 🎯 **Рекомендуемая** - Для Discord, YouTube (лучшая для повседневного использования)
- ⚡ **Быстрая** - Минимальный пинг, баланс скорости и надежности
- 🔒 **Максимальная защита** - Для жестких блокировок
- 🎮 **Только игры** - Оптимизирована для игровых серверов
- 🔥 **Агрессивная** - Максимальные повторы DPI desync

**Провайдер-специфичные стратегии:**
- 📡 Ростелеком, МТС, Билайн, Мегафон, Теле2, ТТК, Эр-Телеком
- Автоматическое определение провайдера и рекомендация оптимальной стратегии

### 🛠️ Функционал

**Основные функции:**
- 🚀 Запуск/остановка обхода с выбором стратегии
- 🔍 **Диагностика системы** - Проверка BFE, TCP timestamps, конфликтов, интернет-соединения, сетевых адаптеров
- 🔧 **Автоисправление** - Автоматическое исправление найденных проблем (BFE, TCP timestamps, файлы, права доступа)
- 🔐 **Шифрование трафика** - Поддержка SOCKS5/SOCKS4/HTTP/HTTPS прокси, TLS туннелирование
- 🌐 **DNS оптимизация** - Тестирование 120+ DNS серверов, автоматический выбор самого быстрого
- 📊 **Статистика** - Отслеживание производительности стратегий, статистика трафика
- ⚙️ **Управление службой Windows** - Установка/удаление/перезапуск службы
- 📥 **Умные обновления** - Автоматическое обновление списков блокировок и проверка обновлений приложения
- 🎨 **Генератор стратегий** - Создание собственных стратегий с настраиваемыми параметрами
- 🧪 **Тест стратегий** - Автоопределение оптимальной стратегии через тестирование доступности сайтов
- 🗑️ **Очистка** - Удаление старых логов и временных файлов
- 💾 **Экспорт/импорт настроек** - Сохранение и восстановление конфигурации

**Дополнительные возможности:**
- Автозапуск с Windows (Registry/Startup folder)
- Работа в системном трее
- Игровой фильтр для оптимизации портов
- Кастомные DNS серверы
- Детальное логирование операций
- Обнаружение конфликтов с антивирусами/VPN/прокси
- Кэширование результатов для оптимизации производительности
- Rate limiting для сетевых запросов

## 🔧 Системные требования

- Windows 7 SP1 или выше
- Права администратора
- Сетевое подключение к интернету
- Base Filtering Engine (BFE) должен быть включен

## 🔍 Диагностика и автоисправление

Диагностика проверяет:
- ✅ Base Filtering Engine (BFE) - запуск службы
- ✅ TCP timestamps - включение через Registry/netsh
- ✅ Интернет-соединение и сетевые адаптеры
- ✅ Наличие всех необходимых файлов
- ✅ Права доступа к файлам
- ✅ Конфликты с антивирусами/VPN/прокси

**Автоисправление:**
- Запуск BFE службы (если остановлена)
- Включение TCP timestamps (несколько методов)
- Обновление списков блокировок
- Исправление атрибутов файлов и прав доступа

## 🔐 Шифрование трафика

Поддержка прокси для дополнительного шифрования:
- **SOCKS5/SOCKS4** - Полное шифрование на уровне приложения
- **HTTP/HTTPS** - Шифрование HTTP/HTTPS трафика
- **TLS туннелирование** - Использование stunnel для TLS
- Авторизация прокси (username/password)
- Тестирование подключения к прокси
- Настройка системного прокси Windows

## 🌐 DNS оптимизация

- Тестирование **120+ DNS серверов** (Cloudflare, Google, Quad9, AdGuard, Yandex и др.)
- Автоматический выбор самого быстрого DNS
- Применение оптимального DNS через WMI
- Измерение времени отклика каждого сервера
- Поддержка IPv4 и IPv6

## 📊 Статистика

- **Статистика стратегий** - Успешность, количество использований, средний процент успешности
- **Статистика трафика** - Отслеживание объема трафика по сессиям
- **История использования** - Последние использованные стратегии

## 🔧 Решение проблем

### Discord/сайты заблокированы
1. Запустите **Диагностику** (автоисправление решит большинство проблем)
2. Попробуйте стратегию для вашего провайдера
3. Используйте **Максимальную защиту** или **Агрессивную**

### Высокий пинг / низкая скорость
1. Используйте **Быструю** стратегию
2. Запустите **DNS оптимизацию** в диагностике
3. Отключите игровой фильтр (если не играете)

### Connection failed в приложениях
1. Проверьте, что обход запущен
2. Используйте **Рекомендуемую** стратегию
3. Запустите диагностику
